## Current priorities

   and JNI contracts without editing BBC/XAX to hide unavailable capability.
2. Complete an isolated baseline and protected APK build, then device verification
   and a restored development build with exact external inputs. The latest
   controlled unsigned lowerings expired at 900/600 seconds and produced no APK.
3. Finish preferred-source delivery, dependency/vendor notice/source closure and
   final project owner review. A private recovery capsule is not source delivery.
4. Establish independent-media recovery and, when resumed by the owner, the
   different-host drill. Same-host VM recovery does not substitute for either.
5. Collect representative repeated build/full-release budgets before production
   acceptance; expand adapters only through separately tested BF-owned passes.
